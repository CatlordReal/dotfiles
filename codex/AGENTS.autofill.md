## Sign-in AutoFill preference

When a task requires sign-in, first try the service’s native AutoFill or saved-account chooser for the intended existing account before asking the user to sign in. Use visible account labels to select the correct identity. Never extract or print stored passwords or one-time codes. If AutoFill is unavailable, the account is ambiguous, or user-only authentication remains, ask the user to complete that step. Preserve normal permission checks and let the user complete 2FA, CAPTCHAs, and system password prompts.
