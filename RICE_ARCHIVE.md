# macOS Catppuccin Rice Archive

This branch preserves the complete Catppuccin rice configuration immediately
before its removal from the Mac on 2026-07-27.

It includes the AeroSpace, SketchyBar, Borders, SketchyVim, Rice Control,
Karabiner, Kitty, Neovim, wallpaper, launch-agent, and lifecycle-script source
needed to inspect or reconstruct the setup.

Generated application binaries and mutable runtime state are intentionally not
tracked. Rebuild Rice Control and Wallpaper Control with:

```sh
~/.config/scripts/rice-control-install.sh
```

The active dotfiles branch remains separate from the Linux-only Neovim setup.
